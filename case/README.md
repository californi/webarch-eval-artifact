# Adoption-Interest Case

This folder freezes the inputs for the illustrative G/C comparison. The target
is an animal-rescue Web/PWA with an implemented Animals baseline, a later
adoption increment, planned domain concepts, and versioned architectural
decisions. It does not contain an implemented adoption-interest module.

The same Evolution Concern is supplied to both conditions. G receives no other
project material. C receives the frozen baseline and Web/domain evidence.
Inputs distinguish current baseline facts, study constraints, and unresolved
questions so that the outputs do not treat planned behavior as implemented.
